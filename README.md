# Beat Vault Afrika

This repository contains a static landing page for a free instrumental marketplace concept inspired by the look and feel of audio streaming and beat sales platforms, with a focus on African producer culture and commercial licensing.

## Features included

- Premium dark music-platform aesthetic
- Hero section and CTA messaging
- Trending beat cards
- Producer spotlight area
- Licensing pricing blocks
- How-it-works section
- Responsive design for mobile and desktop

## Run locally

Open `index.html` directly in a browser, or serve it with a simple local web server:

```bash
python3 -m http.server 8000
```

Then visit:

```bash
http://localhost:8000
```

## Brand direction

Beat Vault Afrika is designed around the idea that:
- fans can stream and download tagged demos for free
- producers sell commercial licenses transparently
- the platform earns a 5% commission on commercial use sales
- producers keep 95% of the sale value

This is a strong starting point for an MVP website and can later be extended into a full application with user auth, beat uploads, licensing checkout, and payout tracking.
